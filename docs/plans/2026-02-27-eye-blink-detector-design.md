# EyeApp - 眨眼识别应用设计文档

> 创建日期: 2026-02-27

## 1. 项目概述

### 1.1 目标

开发一款 macOS 原生菜单栏应用，通过摄像头实时检测眨眼频率，用于：
- **个人健康监测** - 长期追踪眨眼频率，关注眼睛健康
- **工作疲劳提醒** - 检测眨眼频率过低时提醒休息

### 1.2 技术选型

| 项目 | 选择 |
|------|------|
| 平台 | macOS 原生 |
| 技术栈 | Swift + SwiftUI + Vision 框架 |
| 应用形态 | 菜单栏常驻应用 |
| 数据存储 | JSON 文件 + SwiftData |

### 1.3 技术方案

采用 **Apple Vision 框架** 进行人脸特征点检测，通过 EAR (Eye Aspect Ratio) 算法判断眨眼事件。

**选择理由：**
- 原生框架，与 macOS 深度集成
- 无第三方依赖，应用体积小
- 性能优秀，Apple 持续优化
- 开发周期短，维护成本低

## 3. 数据流设计

### 3.1 实时监测数据流

```
摄像头                Vision              眨眼检测
┌─────┐              ┌─────┐              ┌─────┐
│     │   CMSample   │     │  Face        │     │  Blink
│ 📹  │─────────────▶│ 👁️  │─────────────▶│ ⚡  │────────┐
│     │   Buffer     │     │  Landmarks   │     │  Event │        │
└─────┘   (30fps)    └─────┘              └─────┘        │
                                                          │
      ┌───────────────────────────────────────────────────┘
      │
      ▼
  统计引擎                                              持久化
  ┌─────┐              ┌─────┐              ┌─────┐
  │     │  BlinkRecord │     │  Aggregated  │     │
  │ 📊  │─────────────▶│ 📈  │─────────────▶│ 💾  │
  │     │  + timestamp │     │  Stats       │     │
  └─────┘              └─────┘              └─────┘
      │                    │
      │                    ▼
      │              ┌─────┐
      │              │ 🔔  │  疲劳检测
      │              │     │  (频率过低触发提醒)
      │              └─────┘
      │                    │
      └────────────────────┼────────────────────┐
                           │                    │
                           ▼                    ▼
                    ┌─────────────┐      ┌─────────────┐
                    │ 系统通知     │      │ 菜单栏图标   │
                    │ "该休息了"   │      │ 颜色变化     │
                    └─────────────┘      └─────────────┘
```

### 3.2 数据模型

```swift
// 单次眨眼记录
struct BlinkEvent: Codable {
    let id: UUID
    let timestamp: Date
    let confidence: Double  // 检测置信度 0-1
}

// 分钟级统计
struct MinuteStats: Codable {
    let minute: Date        // 精确到分钟
    let blinkCount: Int
    let avgConfidence: Double
}

// 疲劳检测结果
struct FatigueStatus {
    let level: FatigueLevel  // normal / warning / critical
    let blinkRate: Double    // 每分钟眨眼次数
    let recommendation: String
}

// 配置
struct AppConfig: Codable {
    var alertEnabled: Bool = true
    var alertThreshold: Int = 10        // 次/分
    var alertInterval: Int = 15         // 分钟
    var sensitivity: SensitivityLevel = .medium
    var launchAtLogin: Bool = true
}

// 每日数据文件结构
struct DailyBlinkData: Codable {
    let date: Date
    var events: [BlinkEvent]            // 原始事件
    var minuteStats: [MinuteStats]      // 分钟聚合
    var summary: DailySummary           // 日汇总
}

struct DailySummary: Codable {
    let totalBlinks: Int
    let avgBlinkRate: Double
    let fatigueAlerts: Int
    let monitorDuration: TimeInterval
}
```

### 3.3 疲劳检测阈值

| 眨眼频率 | 状态 | 图标颜色 | 操作 |
|---------|------|---------|------|
| > 15 次/分钟 | 正常 | 🟢 绿色 | 无 |
| 10-15 次/分钟 | 轻度疲劳 | 🟡 黄色 | 无 |
| 5-10 次/分钟 | 中度疲劳 | 🟠 橙色 | 系统通知 |
| < 5 次/分钟 | 严重疲劳 | 🔴 红色 | 系统通知 + 图标闪烁 |

## 4. 数据存储设计

### 4.1 存储方案

使用 **SwiftData + JSON 文件** 双重存储：

```
~/Library/Application Support/EyeApp/
├── config.json          # 应用配置
├── blink_events/        # 原始眨眼事件（按日期分文件）
│   ├── 2026-02-27.json
│   ├── 2026-02-26.json
│   └── ...
└── stats_cache.db       # SwiftData 缓存（聚合统计）
```

### 4.2 数据流策略

```
实时数据 → 内存缓冲区 (1分钟)
              │
              ▼ (每分钟)
         写入 JSON 文件
              │
              ▼ (每小时)
         更新 SwiftData 缓存
              │
              ▼
         UI 查询统计
```

## 6. 错误处理

### 6.1 错误类型与处理

| 错误场景 | 检测方式 | 处理策略 |
|---------|---------|---------|
| 摄像头未授权 | 启动时检查 | 显示授权引导界面 |
| 摄像头被占用 | AVFoundation 回调 | 菜单栏图标变灰 + 通知 |
| 检测不到人脸 | Vision 返回空 | 暂停统计，等待重新检测 |
| 磁盘空间不足 | 写入前检查 | 清理旧数据 + 提示用户 |
| 低光环境 | 画面亮度分析 | 菜单栏提示 + 降低检测频率 |

## 8. 限制与已知问题

### 8.1 戴眼镜兼容性

- ✅ 普通近视/远视眼镜 - 兼容良好
- ⚠️ 强烈反光眼镜 - 精度可能下降
- ⚠️ 粗框眼镜 - 部分遮挡时精度可能下降
- ❌ 墨镜/深色眼镜 - 不兼容

### 8.2 环境限制

- 低光环境下检测精度会下降
- 强逆光环境可能影响检测
- 人脸角度过大（>45°）时检测困难
